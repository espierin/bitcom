4.1 Find a proper HLA-A*02:01 PDB model (RCSB)

Goal

Pick a structure that is usable for surface mapping. You want at least:

HLA heavy chain (HLA-A*02:01)

beta2-microglobulin

a bound peptide (preferred, because it orients the groove)

What to do

1. Open RCSB PDB (browser).

2. Search for: HLA-A*02:01

3. Open a candidate structure page and verify it is HLA-A*02:01.

4. Check that the structure contains beta2-microglobulin and a bound peptide.

5. Prefer X-ray or cryo-EM structures (defined coordinates).

6. Pick one PDB entry as your reference model.

Examples of PDB entries that work for HLA-A*02:01 (examples only)

7M8S (HLA-A*02:01 with peptide; useful for groove orientation)

5F9J (HLA-A*02:01 with peptide)

If you need an antibody/Fab present (optional), choose a pMHC structure that includes a Fab chain

Copy / Paste / Save

COPY: PDB ID, title (1 line), and which components are present (heavy chain / beta2m / peptide / extras).

SAVE: Create step4_pdb_model.txt with: Chosen PDB, Reason, Notes (extras present yes/no; method/resolution optional).

?Help me through this step

Open RCSB and search for the example allele from the instructions. On a candidate entry page read the molecule descriptions and chain information. Identify the heavy chain, beta-2 microglobulin and peptide before opening the viewer.

If you get stuck

If your analysed allele differs from the HLA-A*02:01 teaching example, record that difference and align the sequences before transferring positions. Verify example entries on their current structure pages.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

A deposited structure represents a particular construct and bound complex. It may contain a shortened protein, engineered residues or additional molecules. These details affect how you interpret the surface.

4.2 Open the structure in Mol* and clean the view

Goal

Get a clear picture: HLA heavy chain surface plus your residues highlighted.

What to do

1. On the RCSB PDB page, open the 3D View (Mol*).

2. Locate the Sequence panel and the Components/Controls panel.

3. Keep visible: HLA heavy chain, beta2-microglobulin, and peptide.

4. Hide: any extra chains (Fab/TCR/other) if present.

Important

Mol* works by selecting parts of the structure and then applying actions to that selection (color, transparency, representations, or making a separate component).

Copy / Paste / Save

WRITE: In step4_structure_mapping.txt add: PDB used, Viewer (Mol*), and which objects you kept visible.

?Help me through this step

Click 3D View on the structure page. Locate the sequence strip and the Components panel. Hover over a chain or residue to read its identifier. Use the eye icon for a component to change its visibility.

If you get stuck

Rotate by dragging in an empty part of the viewer. If you lose the structure, use the viewer’s reset or focus control. Keep the peptide visible to help orient the groove.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

Components are named selections of the structure. A representation determines how a component is drawn, such as cartoon, sticks or surface. Hiding a component changes the view, not the deposited structure.

4.3 Prepare the residue positions you need to map

Goal

Have a clean list of residue numbers you must highlight.

What to do

1. Open step3_variant_list.txt.

2. Extract only the residue numbers (positions).

3. Write them as a comma-separated list.

Copy / Paste / Save

COPY: Residue positions from step3_variant_list.txt.

WRITE: In step4_structure_mapping.txt add a line: Variant positions to map: 80, 116, 156, ...

RULE: If PDB residue numbering does not match your sequence numbering, document the mismatch (see sanity checks).

?Help me through this step

Write the changed positions from your variant list. Compare the protein sequence around each position with the corresponding PDB chain sequence. Record the matched chain and residue label.

If you get stuck

Do not assume sequence position 1 equals PDB residue 1. Check for a signal peptide, trimmed construct, missing residues and insertion codes. Verify several flanking residues.

4.4.1 Turn on Selection Mode and set Picking Level to Residue

1. Click the cursor icon to enable Selection Mode.

2. Set Picking Level to Residue (so you select whole amino acids, not single atoms).

3. Click a residue once to confirm it becomes highlighted.

CHECK: When you click a residue, it highlights in the 3D view and in the sequence panel.

?Help me through this step

Find the selection cursor control and switch it on. Set the picking level to Residue. Click one residue and read its chain and residue label before continuing.

If you get stuck

If clicking moves the view instead, check that selection mode is active. If an atom alone is selected, recheck the picking level. Viewer versions can place these controls differently.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

Picking level determines the unit selected by a click. Residue selection includes the atoms belonging to an amino acid and is useful for variant mapping.

4.4.2 Select residues from the Sequence panel

1. In Selection Mode, click the residue in the sequence panel at the correct position.

2. To select a range, hold Shift while clicking along the sequence.

3. To select multiple separate residues, use Add/Union selection and click each residue one by one until all are included.

GOAL: You end with one selection that contains all variant residues.

TIP: Use Add/Union selection to accumulate non-adjacent residues.

?Help me through this step

Display the heavy chain in the sequence panel. Find the required residue label, click it and check the corresponding highlight in 3D. Add each additional nonadjacent residue with the add/union control.

If you get stuck

After adding a residue, check that earlier selections remain highlighted. If a click replaces the selection, switch to the add operation and repeat.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

A range selection is convenient for a continuous segment. A union selection combines separate positions, which is useful for several scattered variants.

4.4.3 Select residues by clicking in the 3D canvas

1. Rotate the structure until the region is visible.

2. Click the residue on the 3D model.

3. Use Add/Union selection for multiple residues (same as above).

?Help me through this step

Rotate the model until the intended region is visible. In residue-selection mode click a residue in that region, then read the label and verify it in the sequence panel.

If you get stuck

Nearby surfaces can overlap on screen. Use the sequence panel when it is difficult to pick the intended position. Check the chain label as well as the residue number.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

4.5 Color your selected residues so they stay visible

Goal

Make the mutated residues stand out.

What to do

1. With your residues selected, click Apply Theme to Selection.

2. Choose a strong color and apply it.

3. Confirm that the selection remains visible after you click elsewhere.

WRITE: In step4_structure_mapping.txt add: Color applied to variants: yes/no; How: Apply Theme to Selection (Mol*).

?Help me through this step

Keep the intended residues selected, open the selection actions and apply a contrasting colour. Click elsewhere and check that the colour persists.

If you get stuck

If only the temporary selection highlight appears, create a component from the selection and assign a colour or stick representation to that component. Record which route you used.

4.6 Show the HLA heavy chain as a surface (exposed vs buried)

Goal

Decide if each polymorphism is accessible to antibody binding.

What to do

1. Ensure the HLA heavy chain is visible.

2. Change the representation to include a molecular surface for the heavy chain component.

3. Optional: set the surface slightly transparent so you can still see colored sticks underneath.

DECIDE (for each residue): Exposed (visible on surface), Buried (inside), or Unclear (ambiguous).

SAVE: In step4_structure_mapping.txt create one block per variant: Position, Change, Surface call, Notes (1 line).

?Help me through this step

Find the heavy-chain component and add a molecular-surface representation. Rotate the model and look for the selected position. Toggle the surface or adjust transparency to see the underlying sticks.

If you get stuck

A visible coloured stick through a transparent surface does not by itself establish exposure. Inspect whether the residue reaches the surface and check from more than one angle.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

Surface appearance depends on representation settings and which partners are included. Record whether you assessed the isolated chain or the complex, and compare your observation with the sequence-based prediction.

4.7 Optional: make a separate component for the variant residues (clean pictures)

Goal

Surface plus colored sticks is the clearest way to present results.

What to do

1. Select the variant residues.

2. Use Create Component of Selection with Representation.

3. Choose a representation like sticks.

4. Use the eye icon to show/hide the component.

?Help me through this step

With the variant residues selected, open the selection actions and create a component from that selection. Choose sticks and give the component a descriptive name if the viewer allows it.

If you get stuck

Use the eye icon to toggle the new component. Confirm that only the intended residues disappear and reappear. Keep the heavy-chain surface as a separate component.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

Separating the selected residues makes it easier to combine an overall surface view with a detailed view of the side chains.

?Quick sanity checks (do these before you conclude)

Residue numbers do not exist in the PDB sequence panel: you may have a numbering offset or a trimmed construct. Pick a different PDB entry or document the offset in step4_pdb_model.txt.

Extra chains block the view: hide them using the Components panel (eye icon), or keep only the pMHC components.

Selected residues disappear after clicking elsewhere: apply the theme immediately or create a separate component from the selection.

?Help me through this step

Choose a view where the selected residues and structural context are visible. Use the viewer’s camera or screenshot control, download the image, and save it in your workshop folder.

If you get stuck

Open the downloaded image to check it. Record the PDB ID, chains, mapped residue labels and colour meaning in your notes. Save both an overview and a close-up if one image cannot show everything clearly.
