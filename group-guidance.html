Working together in a group of 40

Keep one workshop tab and your workbook open. Download the fallback package before class, extract all files to one folder, and check that you can open both alignment-results.html and index.html. The first contains saved alignments. The second opens the NetSurfP viewer with the prediction data included.

Download offline alignment and NetSurfP package

  1. Protein alignment. Use SMS2 first. It calculates on each laptop. If the site or results window fails, use the saved protein comparisons. Check both input sequences and the reference, then use the aligned rows to find your positions.
  2. NetSurfP. Watch one facilitator submission, then use the saved-results viewer for the assigned case. If you are invited to submit, keep the job ID and switch to the archive after two minutes, or immediately if the service fails. Record the exact input, residue position and RSA, then write your interpretation.
  3. Unresolved or unmatched input. Document the limitation. For Case 02 genomic or Case 03, keep the genomic splice evidence and use the separately labelled HLA-B example to practise alignment and RSA lookup. If you need a full reference–variant RSA comparison, use Case 01 as a separate practice exercise. Keep demonstration results apart from the assigned case.
  4. Workshop site or Wi-Fi unavailable. Open the extracted package. Use the local alignment text and the offline viewer or the included CSV exports. Keep notes in a local text file until you can return to the workbook.
?Facilitator setup
  1. Distribute the package before the session and keep a second local copy. Ask participants to extract it and open both pages before starting.
  2. Assign the exact input and comparator. Confirm who is working on a genomic splice question, an independent CDS or a supplied protein.
  3. Demonstrate one NetSurfP submission. Have the group use the archive for the interpretation exercise, so everyone can begin together.
  4. For a local browser failure, open the comparison text or per-residue CSV in a text editor or spreadsheet. The workbook can be supplemented with local notes.
!Service capacity and what the archive covers

SMS2 runs its alignment calculation locally after the web page loads. The saved comparisons cover six defined HLA-A input routes and one separate HLA-B pair. The NetSurfP archive contains eight predictions and separate notices for two genomic inputs without an established variant protein.

EMBL-EBI asks users of its Web Services to limit batches to 30 simultaneous jobs and wait before submitting the next batch. UniProt Align uses EMBL-EBI Clustal Omega. DTU documents NetSurfP input limits but gives no reserved capacity for 40 live jobs. Run the shared demonstration and make the archive the group’s working route.
