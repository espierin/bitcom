Saved protein comparisons

Use this route for task 2.7 if SMS2 is slow, its result window is blocked, or the service is unreachable. The saved files require no alignment job.

  1. Open your case and download the exact input pair. Compare both proteins with yours, including lengths and all residues. The HLA-A comparisons use the supplied A*01:01:01:01 workshop reference. If you chose a different BLAST hit, keep that finding and label this saved result as a comparison with the workshop reference.
  2. Download the readable comparison and open it in a plain-text editor. Read the letters in the same column. A vertical bar shows identity, an asterisk marks a substitution, and a hyphen marks a gap. Count letters in each row separately using its residue range.
  3. Record the positions and letters in your variant list. Keep the method, reference and input names with your result. Continue to the NetSurfP archive using the verified protein and its own residue positions.

Case 02 genomic and Case 03: record that the variant protein is unresolved. Use the HLA-B demonstration below for alignment practice and the separately labelled HLA-B prediction for the RSA exercise. Those results belong to the demonstration.

All pairs use SMS2 Pairwise Align Protein, BLOSUM62, gap opening 12, gap extension 2. Download provenance and sequence checksums.
