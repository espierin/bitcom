Start here

The EFI Bioinformatics & IT Committee (BITCom) guides this workshop in two 45-minute blocks. Bring a laptop with a browser and keep a plain-text editor open for your sequences and notes. The core exercise follows an HLA-A reference and a workshop variant through annotation, alignment and interpretation. If this is your first time working with FASTA, start at 1.1 and keep the workshop open in one browser tab. Create a local folder named EFI-HLA-workshop for everything you save. Complete the core case before trying the additional cases.

Working together in a group of 40

Your facilitator will demonstrate one live alignment and one NetSurfP submission for the core pair. Everyone can then inspect the same saved results. Submit additional jobs only when your facilitator invites your group.

If a job is queued or fails, continue with the downloads below. Keep the job identifier and check the existing job later. Repeated submissions create extra work for the server.

  1. For step 2.7, open the complete core protein comparison. Each block gives its residue range. Vertical bars mark agreement and an asterisk marks the substitution. Record the changed position and both residues.
  2. For steps 3.3.1–3.3.2, download the saved NetSurfP predictions. Open the CSV in Excel or a text editor. Find precursor_position 212 for reference and variant and compare amino_acid and RSA.

The predictions come from a completed NetSurfP-3.0 run on the two supplied proteins, retrieved 5 November 2026. Reference raw result · Variant raw result.

Facilitator guidance and service limits

EMBL-EBI asks for batches of at most 30 simultaneous Web Services jobs, waiting for completion before another batch. This is a fair-use limit, not reserved capacity. UniProt Align uses the EBI Clustal Omega service, so switching to that service directly does not provide independent capacity. NetSurfP documents sequence-size limits and a mirror, but gives no guarantee for 40 simultaneous jobs. One shared demonstration plus saved results is the default classroom route. Use the downloaded reference sequences if GitHub or SFAT is slow, and ExPASy for translation if ORFfinder fails.

1.1 Download the reference genomic DNA

  1. Open ANHIG/IMGTHLA → fasta. For this exercise open A_gen.fasta. Click Raw, View raw or the download icon. If the full file opens in your browser, press Ctrl+F (Mac: Cmd+F) and search for A*01:01:01:01.
  2. Find the line starting with > that contains that allele. Copy the DNA on the lines below it, stopping just before the next > line. Paste into Notepad or TextEdit in plain-text mode. Save as your_allele_genomic.txt.
?Help

If you cannot open the large GitHub file, use the reference genomic download above. The sequence is 3,503 bases. Make sure your editor did not add a second .txt extension.

!Explore further

Genomic DNA contains exons, introns and untranslated regions. The FASTA header identifies the record.

1.2 Annotate the reference in SFAT

  1. Open Sequence Feature Annotation Tool (SFAT). Paste the DNA letters from your text file into the sequence field. Select locus A, level Genomic, then click Annotate Sequence Now.
  2. In the Feature Map, look for numbered exons and introns. Record the boundaries. Copy the letters shown under Coding sequence and save as your_allele_CDS.txt.
?Help

Remove the FASTA header before pasting. Expect a CDS of 1,098 bases. If the service fails, use the supplied reference CDS and record that you used the fallback.

!Explore further

The CDS is the spliced coding region. Compare genomic and coding coordinates to see which sequence was removed.

1.3 Save the reference protein

  1. Copy the one-letter Protein sequence from SFAT into your_allele_protein.txt.
  2. To translate it yourself, open ExPASy Translate. Paste the CDS letters, leave Compact and Forward selected, click TRANSLATE!, and read 5′→3′ Frame 1 for this reference. Copy the amino-acid letters up to the terminal dash.
?Help

Expect 365 amino acids. A dash in ExPASy Compact output marks a stop. If you see many dashes, check that you pasted CDS and selected the annotated frame.

!Explore further

The CDS contains 366 codons, including the terminal stop. Record SFAT’s codon_start if it is available.

2.1 Prepare the synthetic allele

  1. Download the exon 4 genomic FASTA above. Open it in your text editor. Copy the sequence lines below the header into a new file named synthetic_input_sequence.txt.
  2. Check that the contents consist of A, C, G and T plus line breaks. Keep the lowercase base if you want to see which position was edited.
?Help

Copy all sequence lines. The sequence is 3,503 bases, the same length as the reference.

!Explore further

This is an exercise variant. Start by analysing the sequence before looking at the supplied protein.

2.2 Annotate the synthetic DNA

  1. Paste synthetic_input_sequence.txt into SFAT. Select A and Genomic. Click Annotate Sequence Now.
  2. Save the output under Coding sequence as synthetic_CDS.txt. Copy the protein if shown and save it as synthetic_protein.txt. Start closest_match_notes.txt and record the locus, input level and codon_start.
?Help

Both reference and exon 4 variant should return 1,098 coding bases. Use the supplied variant CDS and protein if SFAT is unavailable.

!Explore further

If you switch to a supplied CDS exercise, choose level CDS. Use genomic input for checking intron-side splice motifs.

2.3 Translate the synthetic CDS

  1. If SFAT provided a protein, keep that file. To check it independently, paste synthetic_CDS.txt into ExPASy, choose Compact and Forward, then translate.
  2. Use the forward frame corresponding to SFAT’s codon_start. For the exon 4 exercise, this is Frame 1. Save the protein letters in synthetic_protein.txt.
?Help

Keep the 365 amino-acid letters. Leave the terminal dash out of the protein FASTA you will make later.

!Explore further

An early stop may be biologically relevant. Confirm which reading frame you used before interpreting a short translation.

2.4 Find and document a close match with BLAST

  1. Open NCBI Nucleotide BLAST. Paste the synthetic genomic DNA under Enter Query Sequence. Run BLAST. If needed, expand the descriptions or click a hit to inspect its alignment.
  2. In closest_match_notes.txt, record up to three hits with accession or allele name, query coverage, identity, mismatches and gaps. Explain why your selected hit is a suitable comparator. For the rest of the core exercise use A*01:01:01:01, so everyone uses the same reference.
?Help

If the database search is slow, select Align two or more sequences, put the synthetic genomic DNA in Query and the reference genomic DNA in Subject, then run the direct comparison.

!Explore further

For a direct comparison expect a single substitution at genomic position 1885. Database search rankings depend on the selected database, coverage and alignment score.

2.5 Retrieve the reference protein FASTA

  1. Return to the IPD-IMGT/HLA FASTA directory. Open A_prot.fasta, view the raw data and search for A*01:01:01:01.
  2. Copy the header and all amino-acid lines for that entry. Save as reference_protein.fasta.
?Help

If the large file is difficult to navigate, download the reference protein above. The FASTA must have one header starting with >.

!Explore further

Use the same allele as your reference throughout the core exercise.

2.6 Make a FASTA record for the synthetic protein

  1. Create a new plain-text file. Type >synthetic_exon4 on line 1. Paste the amino-acid letters from synthetic_protein.txt on the following lines.
  2. Save as synthetic_protein.fasta. Check that it has one header and 365 amino-acid letters.
?Help

In Windows Notepad, choose All files if needed when saving the .fasta extension. The supplied variant protein FASTA is an equivalent input.

!Explore further

Use distinct, short headers to make the two sequences easy to identify in an alignment.

2.7 Align the two proteins

  1. Open UniProt Align. Paste both complete FASTA records into the same input box, with each header on its own line. Run the alignment when your facilitator invites your group. Otherwise use the shared result.
  2. Locate the mismatch. Save the alignment or copy the relevant lines to uniprot_alignment.txt. Record the residue number and the reference → variant amino acids.
?Help

If the service is unavailable, compare precursor residues 207–217: reference DPPKTHMTHHP, variant DPPKTLMTHHP. The sixth residue in the window is H → L at position 212.

!Explore further

CDS positions 634–636 change CAT to CTT. The precursor has a 24-residue signal peptide, so precursor 212 maps to mature 188.

Part 2 · 13:15–14:00

Interpret and map the change

Jump to Step 3 · Step 4

3.0 Start a variant list

  1. Create step3_variant_list.txt. Enter the precursor position, reference amino acid, variant amino acid and, where known, mature position. Use one line per variant.
?Help

For the core exercise record precursor H212L and mature H188L.

!Explore further

Use precursor numbering with a full FASTA and check the numbering again for a structure.

3.1.1 Check for a premature stop

  1. Paste the synthetic CDS letters into ExPASy Translate. In Compact, Forward Frame 1, locate the first dash and compare it to the reference.
  2. Record your result in step3_truncation_check.txt. For an optional second check, use ORFfinder with standard genetic code and ATG-only start. Find the forward ORF starting at base 1.
?Help

The core variant has 365 residues before the terminal stop. ORFfinder returned an error during testing, so use ExPASy if the job fails.

!Explore further

The additional premature-stop CDS has 219 residues before the first stop. Its 660-base span includes the stop codon.

3.1.2 Check for a frameshift

  1. Compare the reference and synthetic CDS for gaps. For each coding insertion or deletion, record its position and length in step3_truncation_check.txt.
  2. Decide whether the gap length is divisible by three. For a frameshift candidate, translate from the annotated start and check for a changed downstream translation or early stop.
?Help

The core variant is a substitution. The additional exon 2 frameshift CDS contains a one-base insertion. SFAT returned 30 residues for that CDS.

!Explore further

The similarly named genomic file is a separate splice-acceptor substitution example. Use the CDS file to practise a coding insertion.

3.1.3 Inspect splice sites

  1. In the SFAT genomic Feature Map, identify where an exon begins or ends. In the genomic sequence, inspect the bases on the intron side of that boundary.
  2. Compare the usual donor GT immediately after an exon or acceptor AG immediately before the next exon. Record the boundary and change in step3_truncation_check.txt.
?Help

The exon 3 example changes the acceptor AG to AT at positions 1013–1014. SFAT still returned a full-length translation, so inspect the motif directly.

!Explore further

Splice disruption is a hypothesis. If you can map the change to a reference genome coordinate, you can explore it with SpliceAI Lookup.

3.2.1 Compare the ARD at DNA level

  1. For this class I exercise use SFAT coding exons 2 and 3. Copy the exon sequences for reference and variant into step3_ard_check.txt and compare them. Record whether the relative G-group comparison supports identical ARD DNA.
?Help

The relevant CDS interval is 74–619 inclusive. The core change at base 635 is outside it.

!Explore further

For a class II example, the equivalent workshop comparison uses exon 2. Relative sequence identity and an official group designation are separate observations.

3.2.2 Compare the ARD at protein level

  1. Use your alignment and exon mapping to decide whether any ARD amino acid changed. Add your relative P-group conclusion to step3_ard_check.txt.
?Help

For the core pair, the ARD is identical at both levels. The substitution is in the α3 domain.

!Explore further

A synonymous ARD difference can change the DNA comparison while preserving the amino-acid comparison. Check expression separately for null alleles.

3.2.3 Consider the peptide repertoire

  1. Record whether the variant is in the peptide-binding domain. In step 4, look at the residue relative to the bound peptide and revisit your interpretation.
?Help

The core change is outside the ARD. Use the structure to see where α3 sits relative to the peptide-binding platform.

!Explore further

Describe a plausible mechanism and an experiment that could test it.

3.3.1 Run NetSurfP

  1. Open NetSurfP-3.0. Paste both full protein FASTA records into the submission box. For the group exercise, use the saved predictions. Submit a live job when invited by your facilitator, then open the predictions or export CSV.
?Help

Use the protein FASTAs from steps 2.5 and 2.6. Give them different headers so you can identify both results.

!Explore further

RSA is relative solvent accessibility. NetSurfP predicts it from amino-acid sequence.

3.3.2 Read the residue-specific result

  1. In each result look up precursor position 212. Verify the residue letters H and L. Record both RSA values and your interpretation in step3_surface_check.txt.
?Help

The workshop test returned reference H ≈ 0.331 and variant L ≈ 0.360. Use those as checkpoints or if the service is unavailable.

!Explore further

Compare accessibility in the reference structure, which contains His and interaction partners.

3.3.3 Check Bw4/Bw6 relevance

  1. Using mature numbering, check whether the change falls in residues 77–83. If it does, compare both motifs and record the result in step3_surface_check.txt.
?Help

The core mature residue is 188, outside this motif.

!Explore further

Use allele and locus context when interpreting a 77–83 change.

3.3.4 Consider antibody recognition

  1. Record whether the residue is exposed and whether it might lie in an antibody-accessible region. Optionally check the position in the HLA Eplet Registry.
?Help

Record eplet overlap as unknown if you cannot verify it.

!Explore further

Exposure can motivate a binding experiment. An eplet overlap and evidence for an antibody specificity are different observations.

3.3.5 Consider NK recognition

  1. Add a line about whether the change affects the Bw4 motif or a known receptor-facing region. Explain your evidence or uncertainty.
?Help

The core example provides no motif change at 77–83.

!Explore further

If proposing a receptor effect, specify the receptor and the comparison you would test.

3.3.6 Consider direct T-cell recognition

  1. Record whether the change is in the ARD and on a surface a TCR could approach. Summarise your evidence in step3_surface_check.txt.
?Help

Use the bound peptide in the structure to orient yourself. Core residue 188 is in α3.

!Explore further

Separate a direct TCR-contact hypothesis from other effects on the pMHC complex.

4.1 Choose a reference structure

  1. Open RCSB PDB entry 3BO8. On the entry page identify the HLA-A1 heavy chain, beta-2 microglobulin and the MAGE-A1 peptide. Record the PDB ID and why you chose it in step4_pdb_model.txt.
?Help

Use chain A for the HLA heavy chain. This entry contains the reference histidine at mature position 188.

!Explore further

For another allele, look for the closest suitable structure with the relevant residue resolved. Check sequence identity and construct boundaries.

4.2 Open Mol* and identify the chains

  1. Click 3D View. Locate the sequence panel and the Components panel. Identify chain A, beta-2 microglobulin and the peptide. Keep those visible and use the eye controls to hide any additional components if present.
?Help

Hover over a chain or residue to read its label. Save the viewer and components in step4_structure_mapping.txt.

!Explore further

Keeping the peptide visible helps you identify the groove.

4.3 Map the sequence position

  1. Compare the FASTA with the chain sequence. For this pair, subtract the 24-residue signal peptide from precursor 212 to get mature 188. Check that chain A residue 188 is His. Write down both positions.
?Help

Look at the actual residue label in Mol*. A chain can have author numbering, missing residues or a trimmed construct.

!Explore further

For other structures, use a sequence alignment and verify flanking residues before trusting a fixed offset.

4.4 Select the residue

  1. Turn on Selection Mode using the cursor icon. Set the picking level to Residue. In the chain A sequence panel click His 188 and check the highlighted position in 3D.
  2. For several nonadjacent residues, use the selection add/union control and verify each label.
?Help

If the sequence panel starts on a different chain, switch it to chain A first.

!Explore further

You can also rotate the model and pick a residue in the 3D canvas, then check its label in the sequence panel.

4.5 Make the selected position visible

  1. With His 188 selected, apply a contrasting colour with the selection theme controls, or create a selection component with a stick representation. Confirm the location remains visible when you move the pointer away.
?Help

If a selection theme is difficult to find, keep the residue selected and use the highlighted view to inspect it.

!Explore further

A separate selection component lets you toggle the residue without hiding the heavy chain.

4.6 Inspect the molecular surface

  1. In Components, add or change the HLA heavy-chain representation to a molecular surface. Rotate the structure. Inspect whether the selected residue reaches the surface and where it lies relative to the peptide and beta-2 microglobulin.
  2. Record exposed, buried or unclear with your reasoning in step4_structure_mapping.txt.
?Help

If the surface hides the selected residue, make it partly transparent or toggle it while keeping the stick component.

!Explore further

Compare the structural view with NetSurfP. Note that the deposited structure represents the reference sequence.

4.7 Optional: keep a separate residue component

  1. Select the residue again. Use the selection actions to create a component from the selection and choose sticks. Toggle its visibility to check that the selection is correct.
?Help

Use the selection component only for the residues you intend to label.

!Explore further

A surface view plus coloured sticks makes the mapping easier to explain to another participant.

4.8 Export and summarise

  1. Frame the structure so that the heavy-chain surface, peptide and selected residue can be seen. Use the camera or screenshot control. Save as step4_HLA-A0101_surface_variants.png and record the filename.
  2. Write up to five bullets covering coding integrity, ARD and G/P comparison, accessibility, the structure position, and one testable immunological hypothesis.
?Help

State which tools you completed, which fallback you used and any uncertainty in the mapping.

!Explore further

Compare your conclusion with another participant who analysed a splice or truncation example.

Case 01

Genomic DNA · CDS · Protein

!Detailed answer

Exon 4 substitution

Genomic position 1885 A→T maps to CDS position 635. The codon CAT changes to CTT, giving H212L in the precursor and H188L in mature numbering. The protein remains 365 residues long. The change is outside the ARD, in the α3 region. NetSurfP predicted RSA of about 0.331 for the reference histidine and 0.360 for the variant leucine. In PDB 3BO8, inspect chain A His 188.
