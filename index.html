Part 1 · 45 minutes

From DNA to an aligned protein

1. Annotate the reference

Download the HLA-A*01:01:01:01 reference. Open the genomic FASTA and paste only its sequence into SFAT. Select locus A and level Genomic, then run annotation. Record the exon boundaries and save the CDS and protein output.

Genomic DNA · Reference CDS · Reference protein

?Help

A FASTA header starts with >. Paste the DNA letters beneath it into SFAT. If the protein output is unavailable, use ExPASy Translate on the CDS and use the annotated coding frame.

!Explore further

Compare the CDS with the genomic input. Which intervals were removed during splicing?

2. Annotate the exon 4 variant

Repeat step 1 using the exon 4 genomic example. Keep the reference and variant outputs separate. Use the supplied CDS and protein if annotation is unavailable.

Genomic DNA · CDS · Protein

?Help

Select the input level that matches the file you pasted. Genomic DNA contains introns. CDS is the spliced coding sequence.

!Explore further

Open NCBI Nucleotide BLAST and compare query coverage, identity and gaps for the best hits. A close hit supports a candidate reference for comparison.

3. Align and record the change

Paste the reference and variant protein FASTA records, each with its own header, into UniProt Align. Run the alignment and record each changed residue with its position and both amino acids.

?Help

Use the protein FASTA downloads above. If you create FASTA from SFAT output, put >reference and >variant on their own header lines, each followed by its sequence.

!Explore further

Record whether your position includes the signal peptide. You will need this when comparing the alignment with a structure.

Part 2 · 45 minutes

What could the change affect?

4. Check coding integrity

Use NCBI ORFfinder on the variant CDS. Compare the coding span and protein length to the reference. Record whether an early stop, frameshift or splice-site change is supported by your inputs.

?Help

Start with the annotated coding frame. For a suspected frameshift, inspect the indel length in a coding alignment. For a splice change, use the genomic sequence to check the exon boundary.

!Explore further

Try the premature-stop or splice-site example in Downloads. Which observation distinguishes the two mechanisms?

5. Check the antigen recognition domain

Compare exons 2 and 3 for this class I example. Record whether the ARD nucleotide sequence differs and whether the encoded ARD amino acids differ. Use the IPD-IMGT/HLA alignment tool for reference exon comparisons.

?Help

Use exon annotations from step 1 to locate the relevant sequence. Compare DNA for the relative G-group question and amino acids for the relative P-group question.

!Explore further

Compare a synonymous change with a missense change. How could they produce different conclusions for G and P grouping? Consider expression separately for null alleles.

6. Predict exposure and map the residue

  1. Submit the variant protein to NetSurfP. Record the relative solvent accessibility (RSA) at the variant position.
  2. Find an HLA-A structure in RCSB PDB with a resolved region corresponding to your change. Open its 3D view (Mol*).
  3. Align the heavy-chain sequence to your reference, locate the equivalent residue and compare the structure view with the RSA prediction.
?Help

Use the Mol* sequence panel to select the heavy-chain residue, then display the heavy chain as a surface. Check the sequence alignment before selecting a residue number, especially if the structure lacks the leader or contains a trimmed construct.

!Explore further

Record whether the change faces the peptide groove or an exposed surface. Discuss how this location could influence antibody or receptor recognition, and what evidence would test that hypothesis.

7. Write your conclusion

Use up to five bullets to report coding integrity, ARD and relative G/P findings, surface exposure, the structural location and one testable immunological hypothesis.

?Help

Include the reference allele, numbering convention and any ambiguity in your structural mapping.

!Explore further

If the prediction and the reference structure give different impressions, consider missing residues, the peptide or interaction partners, and whether the structure contains the variant itself.
