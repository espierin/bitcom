2.1 Clean the synthetic DNA sequence and save it

Goal: you start with a provided synthetic DNA sequence. Before analysis, make sure it contains only DNA letters (A/C/G/T) and nothing else.

What you do

Copy a synthetic DNA sequence from the workshop materials (GitHub).

Open Notepad (or similar) and paste the sequence.

Clean the sequence: remove spaces, line numbers, headers, and any other characters.

Keep only A/C/G/T.

Save the cleaned sequence as synthetic_input_sequence.txt.

Copy / Paste / Save

COPY: the full synthetic DNA sequence from the workshop materials.

PASTE: into Notepad (scratchpad).

CLEAN: remove spaces, line numbers, headers, and any non-ACGT characters.

SAVE: as synthetic_input_sequence.txt

What you have now

One clean DNA sequence (A/C/G/T only) that you can safely paste into web tools.

?Help me through this step

Open Downloads in a second tab and choose the case assigned by your facilitator. Read the link label to identify genomic DNA, CDS or protein. For this step choose the DNA input. Open it in a plain-text editor before copying.

If you get stuck

Remove the header line and any numbers or formatting. Convert lowercase letters to uppercase if needed. Compare the cleaned sequence with the original to check that you did not lose sequence lines. Save it with the exact filename used below.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

Cleaning removes presentation characters. If you see an unfamiliar nucleotide symbol inside the actual sequence, ask the facilitator what it represents before deleting it. Deleting a biological symbol changes the sequence and its coordinates.

Write down what you observed, then explain how it supports your interpretation. For a worked case answer, open the matching case on the Downloads page and expand its Detailed answer.

2.2 Convert synthetic DNA to exons/CDS (and often protein) with SFAT

Goal: analyse the synthetic DNA with SFAT so you can identify exon/intron features (if present), generate the CDS (exons stitched together), and obtain a correct protein sequence.

Tool to use

IPD-IMGT/HLA Sequence Feature Annotation Tool (SFAT).

What you do (click-by-click)

Open the Sequence Feature Annotation Tool page.

Paste your genomic DNA letters only (no FASTA header, no spaces).

Select the locus that matches your sequence (e.g., A, B, DRB1, MICB, etc.).

Select Level: Genomic (because your input includes both the exons and the introns).

Run the annotation by pressing the “Annotate Sequence Now” button.

Copy / Paste / Save

COPY: the full content of synthetic_input_sequence.txt

PASTE: into SFAT (letters only; no header).

SELECT: locus + correct Level (Genomic or CDS).

SAVE: copy CDS output into synthetic_CDS.txt

SAVE: if SFAT provides translation output, copy protein into synthetic_protein.txt

WRITE DOWN: locus selected + level selected + codon_start (if shown) in closest_match_notes.txt

What to look for in the results

Exon/intron boundaries (where each exon starts/ends in your input). Note: splice changes can introduce premature stops and cause null alleles.

A coding sequence: exonic sequence stitched together (introns removed).

A codon_start / reading-frame hint (important for correct translation).

The translated protein sequence.

?Help me through this step

Keep your reference output open in another tab or save it first. Paste the synthetic DNA into a new SFAT run. Set the correct locus and select Genomic or CDS to match the downloaded input. Save each output with synthetic in its filename.

If you get stuck

Look for the coding sequence, translated protein, exon boundaries and codon_start. Copy sequence letters from the sequence output rather than the entire annotated report. Note warnings and keep the input file that produced them.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

A boundary prediction is useful evidence for annotation. For a suspected splice change, inspect the actual genomic bases at the boundary as well. A generated translation can assume an exon structure even when a variant may change splicing.

Write down what you observed, then explain how it supports your interpretation. For a worked case answer, open the matching case on the Downloads page and expand its Detailed answer.

2.3 Translate the CDS into protein (if not provided by SFAT)

Goal: ensure you end Step 2 with a correct one-letter amino-acid sequence so you can run protein-level comparisons.

Option A (preferred): take the protein directly from SFAT output

In the SFAT results, find the Protein section.

Copy the one-letter amino-acid sequence into synthetic_protein.txt.

Copy / Paste / Save

COPY: the one-letter amino-acid sequence from the SFAT translation output.

SAVE: as synthetic_protein.txt

Option B (manual/universal): translate the CDS with ExPASy Translate

Open ExPASy Translate.

Paste the CDS (from synthetic_CDS.txt) — not the genomic DNA.

Choose an output format (compact/continuous sequence).

ExPASy shows 6 possible frames (3 forward, 3 reverse).

If SFAT provides codon_start, use it to pick the correct forward frame: start=1 (in SFAT) -> frame 1 (in ExPASy); start=2 (in SFAT) -> frame 2 (in ExPASy); start=3 (SFAT)-> frame 3 (in ExPASy).

Copy the protein sequence into synthetic_protein.txt.

Optional: download all frames as a text file.

Copy / Paste / Save

COPY: the full content of synthetic_CDS.txt

PASTE: into ExPASy Translate.

CHOOSE: the correct frame (use SFAT codon_start).

SAVE: as synthetic_protein.txt

?Help me through this step

Use the protein from the synthetic SFAT result if available. Otherwise open ExPASy, paste synthetic_CDS.txt and translate. Read the forward frame indicated by the annotation. Save the result as synthetic_protein.txt.

If you get stuck

Make sure the input is your synthetic CDS. Check the filename before pasting. If your output differs markedly from the reference, return to the input and frame settings and record the difference once you have checked them.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

Six-frame translation shows three possible starting positions on each strand. The annotated strand and coding start determine which is relevant to your allele. Choosing the longest-looking sequence without checking the annotation can select the wrong frame.

Write down what you observed, then explain how it supports your interpretation. For a worked case answer, open the matching case on the Downloads page and expand its Detailed answer.

2.4 Find the closest known allele (NIH BLAST)

Goal: determine which known allele your synthetic sequence most closely resembles, and document why it looks novel relative to that closest match (identity, coverage, mismatches).

Preferred tools to use

Basic Local Alignment Search Tool: https://blast.ncbi.nlm.nih.gov/Blast.cgi

Alternative for HLA: There are lots of different BLAST services out there to use, but these may or may not have the same library of sequences to compare against or give the same results. Why not repeat the step above using the service at the EBI, https://www.ebi.ac.uk/jdispatcher/sss/ncbiblast? How do the results differ, why might this be?

For DNA sequences: Nucleotide -> Nucleotide BLAST

For protein sequences: Protein BLAST

What you do (Nucleotide similarity)

Go to the BLAST website: https://blast.ncbi.nlm.nih.gov/Blast.cgi (https://www.ebi.ac.uk/jdispatcher/sss/ncbiblast/nucleotide)

Your sequence contains DNA sequences, thus select the option: Nucleotide BLAST nucleotide -> nucleotide

Enter your Query Sequence in the text box.

Press the blue BLAST button on the lower left of the page and wait.

The output contains a list of sequences that are (partially) identical to your sequence, sorted by percent identity.

The closest matching HLA variant is on the top of that list.

You can inspect the homology in an alignment by clicking on the description.

It may make sense to select the one that has been described as “Complete CDS”.

Identical nucleotides are connected by a “|” between your query sequence and the obtained homologous subject. For mismatches, this symbol is missing.

Copy / Paste / Save

COPY: sequence from the appropriate file (genomic).

PASTE: into the matching NIH BLAST page.

RUN: keep defaults unless instructed otherwise.

SAVE: in closest_match_notes.txt record the top 3 hits for each run: allele name, % identity, alignment length/coverage, mismatches/gaps.

WRITE: 1–2 sentences: closest known allele + evidence + novelty evidence (differences at ...).

?Help me through this step

Choose Nucleotide BLAST for DNA. Paste your sequence into the query box. Record the database and options used, press BLAST once, and keep the results tab open. Save the job identifier if a queue page appears.

If you get stuck

For each candidate, read query coverage and percent identity together. Click its description to inspect the aligned region. A short perfect match can cover only a small part of your query. Record the top candidates before deciding which gives the most useful comparison.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

The ordering can depend on alignment score and the selected sorting column. The first hit alone does not establish the closest full-length allele. Complete CDS describes a coding record, which may cover only part of a genomic query. Record why you selected your comparator.

Write down what you observed, then explain how it supports your interpretation. For a worked case answer, open the matching case on the Downloads page and expand its Detailed answer.

2.5 Align your synthetic protein with the closest matched allele (UniProt Align)

Goal: retrieve the protein sequence of the closest matched allele (the reference) from the ANHIG/IMGTHLA GitHub repository, and save it as a single FASTA entry.

What to do

Open the ANHIG/IMGTHLA repository in your browser.

Open the folder: fasta/

Open the protein file for your locus: X_prot.fasta (where X is the gene/locus, e.g., A_prot.fasta, DRB1_prot.fasta, MICB_prot.fasta). View the raw data file.

Find your closest matched allele entry in the file (use Ctrl+F).

Copy the entire FASTA entry: the header line starting with '>' AND the amino-acid sequence lines below it.

Copy / Paste / Save

COPY: Copy the full FASTA entry for the closest matched allele from X_prot.fasta (including the '>' header).

PASTE: Paste into Notepad/TextEdit as your scratchpad.

CHECK: You should see exactly one header line starting with '>' followed by only amino-acid letters (no numbers, no spaces).

SAVE: Save as reference_protein.fasta

What you have now

• A reference protein sequence for the closest matched allele, stored as FASTA (header + sequence) file.

?Help me through this step

Write down the exact allele name selected in the previous step. Open the protein FASTA file for that locus and search for that name. Copy its > header plus all following sequence lines up to the next header.

If you get stuck

Paste into a new text file and check that there is exactly one > header. Save as reference_protein.fasta. If the browser struggles with a large file, download it first and search in a text editor.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

The comparison is informative only when you know which reference you used. Alleles with similar names can differ in sequence. Keep the reference allele name alongside the alignment and all later interpretations.

2.6 Convert your SFAT protein output into FASTA format

Goal: your SFAT protein file often contains only the amino-acid letters. UniProt Align expects FASTA formatting, so you will add a header line and save it as a FASTA entry.

What to do

Open synthetic_protein.txt (your protein sequence from SFAT).

Create a new text file in Notepad/TextEdit.

Add a FASTA header line on the first line, starting with '>' (example: >synthetic_novel_allele).

Paste your protein sequence on the next lines (letters only; line wrapping is optional).

Save as synthetic_protein.fasta

Copy / Paste / Save

COPY: Copy the amino-acid letters from synthetic_protein.txt

PASTE: Paste into a new file under a header line like: >synthetic_novel_allele

CHECK: The file must contain two things only: one '>' header line and amino-acid letters (no '*', no spaces).

SAVE: Save as synthetic_protein.fasta

What you have now

• A FASTA-formatted protein entry for your synthetic allele.

?Help me through this step

Create a plain-text file with >synthetic_novel_allele on the first line. Press Enter, then paste the protein letters below it. Save as synthetic_protein.fasta. In Notepad, selecting All files can prevent an extra .txt extension.

If you get stuck

Open the saved file again. It should contain one header followed by protein letters. Remove copied line numbers and labels. Record any stop already identified in your notes and prepare the relevant translated protein segment for alignment.

Keep the output file named in the instructions and note any setting or fallback you used. You can reopen this help while working in another browser tab.

!Understand what you are doing

FASTA is a simple text format. The > line names the sequence, while the following lines contain it. Line wrapping is allowed. Two records require two headers so the tool can identify the sequences separately.

Write down what you observed, then explain how it supports your interpretation. For a worked case answer, open the matching case on the Downloads page and expand its Detailed answer.

2.7 Align the two proteins with the UniProt Align web tool

Goal: generate a protein alignment between your synthetic allele protein and the closest matched allele protein, so you can see the exact amino-acid differences in context.

What to do (click-by-click)

Open the UniProt Align tool in your browser.

In the sequence input box, paste BOTH FASTA entries, one after the other:

First: your synthetic protein FASTA (synthetic_protein.fasta)

Second: the reference protein FASTA (reference_protein.fasta)

Keep the default settings unless the instructor tells you otherwise.

Click Run Align.

In the results, locate the positions where the sequences differ (mismatches, gaps).

Copy the alignment output (or download if available) and save it for your notes.

Copy / Paste / Save

COPY: Copy the full FASTA text from synthetic_protein.fasta and reference_protein.fasta

PASTE: Paste both into the UniProt Align input box (two FASTA entries in one box).

RUN: Click Run Align.

SAVE: Copy the alignment result into uniprot_alignment.txt. Add 1–2 sentences: what is the closest match, and which residues differ.

What to look for in the results

Are there gaps? (Often indicates an insertion/deletion relative to the reference).

Are the differences clustered (e.g., ARD region) or scattered?

Do you see any '*' stop symbols? If yes, your input may contain a stop codon or a translation issue.

?Quick sanity checks (worth 20 seconds)

SFAT fails or gives nonsense features: you probably pasted spaces/headers or picked the wrong locus/level.

Translation shows many stop codons (*): you translated genomic DNA instead of CDS, or selected the wrong frame.

BLAST hit looks short: check coverage/alignment length; you may have pasted only part of the sequence.

Did you paste FASTA headers for BOTH sequences? Each sequence must start with a line beginning with '>'.

Did you accidentally paste DNA instead of protein? Protein should not contain A/C/G/T-only patterns and should not contain long stretches of only four letters.

Are you aligning proteins from the same locus? Aligning A vs B will give nonsense.

If the alignment looks shifted: re-check for missing residues at the start (signal peptide / leader) and confirm you copied the full entry from X_prot.fasta.

Output you will reuse in Step 3

Use the alignment to update your amino-acid variant list (position + AA change). This becomes the input for surface-exposure and antibody-relevance checks in Step 3.

Save the following results:

synthetic_input_sequence.txt (DNA)

synthetic_CDS.txt (CDS)

synthetic_protein.txt (protein)

Closest known allele from this step (from IPD-IMGT/HLA BLAST)

Paste the complete synthetic FASTA, then a line break, then the complete reference FASTA. Verify that you can see two > headers with different names. Start one job and keep the results tab open.

Follow the group submission instructions. If the service fails, the Group guidance page provides the saved Case 01 comparison. Those results apply to Case 01. For another case, ask the facilitator for a corresponding result.

!Understand what you are doing

Alignment columns describe correspondence between sequences. Gap characters occupy columns without adding a residue. When reporting a change, record the residue number in the relevant sequence as well as the reference and variant letters.
